# 메트로 월드 패스

전 세계 지하철역을 한 정거장씩 탐험하는 브라우저 게임입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 도시와 노선

| 도시 | 노선 |
|---|---|
| 서울 | 수도권 전철 18개 노선 전 구간, 560개 역 (아래 참고) |
| 오사카 | 오사카부를 지나는 철도 54개 노선(지하철·JR·사철·모노레일·노면전차), 678개 역 (아래 참고) |
| 도쿄 | 야마노테선, 긴자선, 마루노우치선 |
| 뉴욕 | 1, 4·5(급행), 7, L 라인 |
| 런던 | 센트럴, 빅토리아, 피카딜리, 주빌리선 |
| 파리 | 1·4·6호선 |
| 홍콩 | 아일랜드, 취안완, 관당선 |

서울 외 도시는 노선마다 주요 역을 골라 실제 운행 순서대로 이은 간략도입니다. 환승역은 노선끼리 공유됩니다.

## 서울 (수도권 전철)

1~9호선, 경의·중앙선, 공항철도, 경춘선, 수인·분당선, 신분당선, 우이신설선, 신림선, 서해선, 김포골드라인의 모든 역을 담았습니다.

- 지선도 따로 이어 두었습니다: 1호선 경인·경부·장항선 구간과 광명·서동탄 지선, 2호선 성수지선·신정지선, 5호선 하남·마천 방면, 6호선 응암순환, 경의선 서울역 방면.
- 역 좌표는 서울 열린데이터광장 「서울시 역사마스터 정보」(`data/seoul_station_master.json`)를 그대로 써서, 지도가 실제 지리와 같은 모양입니다. 겹치는 역만 살짝 떨어뜨립니다.
- 아직 넣지 않은 노선: GTX-A(구간 운행 중), 인천 1·2호선, 경강선, 의정부·용인 경전철 등 서울을 지나지 않는 노선.

역 순서는 `tools/build_seoul.py`의 `LINES`에 적혀 있습니다. 고친 뒤 다음을 실행하면 좌표를 찾아 검사하고 `index.html`에 데이터를 다시 넣습니다.

```
python3 tools/build_seoul.py           # 검사 + index.html 갱신
python3 tools/build_seoul.py --check   # 검사만
```

검사 항목: 좌표가 없는 역, 같은 이름의 다른 역(예: 5호선 양평과 중앙선 양평은 `양평#중앙`처럼 구분), 진행 방향이 되돌아가는 순서 실수, 가장 긴 역 간격 목록.

## 조작

- 지도: 드래그로 이동, 휠·핀치로 확대. 멀리서 볼 때는 환승역 이름만 보입니다.
- 왼쪽 위 검색창에서 역 이름을 찾으면 그 역으로 지도가 이동하고, 현재 위치에서의 최단 시간이 나옵니다.

## 오사카 (오사카권 철도)

오사카부에 역이 하나라도 있는 철도 노선 54개를 모두 담았습니다: 오사카 메트로 9개, JR 서일본 12개(오사카순환선·교토선·고베선·도자이선·한와선 등), 한큐 5개, 한신 2개, 게이한 3개, 난카이 7개, 긴테쓰 9개(케이블 포함), 기타오사카큐코, 오사카 모노레일 2개, 한카이 노면전차 2개, 노세전철, 미즈마철도.

- **범위**: 교토·고베·나라·와카야마까지 이어지는 구간은 넣고, 간사이 밖(긴테쓰 오사카선의 미에현 구간)은 잘랐습니다. 신칸센은 넣지 않았습니다.
- **같은 역**: 이름이 같고 800m 안에 있으면 한 역입니다(JR 덴노지와 지하철 덴노지 등). 이름이 같아도 멀리 떨어진 역(JR 아마가사키와 한신 아마가사키 등)은 따로입니다.
- **도보 환승**: 이름이 달라도 400m 안에 있으면 걸어서 갈아탈 수 있습니다(JR 오사카 ↔ 우메다 ↔ 한큐 오사카우메다 등, 81곳). 지도에는 점선으로 표시됩니다.
- **직통 운행 13개**: 탄 채로 다른 회사 노선으로 넘어갑니다.
  - 사카이스지선 ↔ 한큐 센리선·교토선, 주오선 ↔ 긴테쓰 게이한나선, 미도스지선 ↔ 기타오사카큐코
  - 한신 ↔ 긴테쓰 나라선(고베산노미야–긴테쓰나라), JR 도자이선 직통, JR 간쿠쾌속, JR 직통쾌속(신오사카–나라)
  - 난카이 공항선·센보쿠선, 게이한 나카노시마선, 긴테쓰 나가노선
  - 노선 전체가 직통 열차에 들어가는 경우(미도스지선 등)는 실제처럼 직통 열차로만 다닙니다.
- **역 이름**: 가나 읽기를 외래어 표기법(일본어)에 맞춰 한국어로 자동 변환합니다(주소 十三, 하나텐 放出, 구니지마 柴島). 가타카나 역명과 관용 표기(미노오, 산노미야 등)는 직접 고쳤습니다. 원문 일본어도 함께 보여 주고, 검색은 둘 다 됩니다.
- **데이터**: [Seo-4d696b75/station_database](https://github.com/Seo-4d696b75/station_database)(駅データ.jp 기반, 2026-09-30판). `tools/fetch_osaka.py`로 받아 `data/osaka/lines.json`에 저장합니다.

```
python3 tools/fetch_osaka.py           # 최신 데이터 받기
python3 tools/build_osaka.py --check   # 검사 + 자동 변환 예시 보기
python3 tools/build_osaka.py           # index.html 갱신
```

검사 항목: 원본에 없는 노선, 잘림이 의심되는 긴 역 간격, 직통 구간 연결, 한국어 표기가 필요한 가타카나 역명, 손으로 확인한 지하철 역명 88개와 자동 변환 결과 비교.

## 타는 법

1. **승강장**: 역명판(← 이전 역 · 현재 역 · 다음 역 →)을 보고 탈 열차를 고릅니다. 열차는 실제 운행 계통대로 나뉩니다. 예: 시청 1호선 `인천행`·`신창행`·`연천행`, 2호선 `내선순환`·`외선순환`.
2. **열차 대기**: 1~3분 기다리면 열차가 들어오고 문이 열립니다.
3. **탑승**: 열차가 지도 위 선로를 따라 달리고 화면이 따라갑니다. 객실 안내판에 "다음 역은 ○○역입니다", "○○선으로 갈아타실 수 있습니다"가 나오고, 앞으로 지날 역과 환승 노선이 보입니다.
4. **하차**: 열차는 역마다 섭니다. 정차 중에 `지금 내리기`(Space)를 누르거나, 달리는 중에 `다음 역에서 내리기`를 눌러 두세요. 아무것도 누르지 않으면 그대로 지나갑니다. 종착역에서는 모두 내립니다.
5. **환승**: 내린 역에서 다른 노선 열차를 고르면 환승 통로를 걸어갑니다(4분).

`속도` 버튼으로 열차를 ×1·×2·×4 빠르게 할 수 있습니다.

## 규칙

- 한 정거장 2분, 환승 통로 4분, 열차 대기 1~3분.
- 열차가 처음 서는 역마다 스탬프 +10점.
- 미션역(빨간 깃발)에서 제한 시간 안에 **내리면** 50점 + 남은 1분당 5점. 늦으면 10점. 지나쳐 버리면 돌아와야 합니다.
- 한 노선의 모든 역을 방문하면 노선 배지 +100점, 도시의 모든 역을 방문하면 +300점.
- 진행 상황은 브라우저 localStorage에 저장됩니다. 여권 화면에서 초기화할 수 있습니다.

## 노선 추가하기

`index.html` 상단의 `CITIES` 배열에 도시를 추가합니다.

- `lines[].st`: 운행 순서대로 나열한 역 이름. 순환선은 `loop: true`.
- `geo`: 위치 기준점 `{ "역 이름": [위도, 경도] }`. 각 노선의 양 끝역과 환승역에는 꼭 넣어 주세요. 기준점이 없는 역은 앞뒤 기준점 사이에 고르게 배치된 뒤, 간격이 고르게 펼쳐집니다.
- `facts`: 역에 도착하면 보여 줄 짧은 이야기.
