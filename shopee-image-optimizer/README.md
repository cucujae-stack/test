# 🛍 Shopee Image Optimizer

쇼피 썸네일·SNS 이미지를 브라우저에서 바로 압축하는 웹 도구입니다.
서버에 이미지를 업로드하지 않고 클라이언트(Canvas API)에서만 처리합니다.

## 설치 및 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속

## 주요 기능

### 이미지 입력
- 클립보드 붙여넣기 (Ctrl+V / Cmd+V)
- 드래그앤드롭
- 파일 선택 버튼
- JPG, JPEG, PNG, WEBP 지원 / 여러 장 동시 업로드

### 압축 모드

| 모드 | 캔버스 | 배경 | 기본 목표 용량 |
|------|--------|------|----------------|
| Shopee | 1080x1080 | 흰색 (contain) | 70 KB 이하 |
| SNS | 1080x1350 | 흰색 (contain) | 선택 가능 |
| 기본 | 원본 비율 유지 | - | 선택 가능 |

### 자동 압축 로직
1. 긴 변 기준 최대 1600px에서 시작
2. 품질 0.9 -> 0.35 (0.05 단계) 반복
3. JPG / WEBP 중 더 작은 포맷 자동 선택
4. 목표 초과 시 해상도 90%씩 축소 (최소 긴 변 300px)
5. 최종 Blob 크기 검증 후 결과 표시

### 결과 표시
- 원본 / 압축 후 미리보기 나란히 표시
- 용량, 해상도, 압축률, 적용 포맷 표시
- 개별 다운로드 버튼

### 일괄 처리
- 여러 장 동시 업로드 -> 순차 압축
- 전체 ZIP 다운로드 (optimized-images.zip)

## 기술 스택

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- JSZip (전체 ZIP 다운로드)
- 이미지 처리: Canvas API (클라이언트 전용, 서버 업로드 없음)

## 개인정보

이미지는 브라우저에서만 처리되며 서버에 업로드되지 않습니다.
