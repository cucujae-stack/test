# 화실 담 — 엄마 그림 판매 사이트

`index.html` 한 파일로 된 정적 사이트입니다.

## 고치는 곳 (index.html 안 `<script>` 맨 위)
- `SITE`: 카카오톡 오픈채팅 주소, 인스타그램 아이디, 이메일
- `WORKS`: 작품 목록 (제목, 호수, 크기, 가격, 상태 `sale`/`hold`/`sold`, 설명)
  - 실제 사진은 `images/` 폴더에 넣고 `img: "images/파일명.jpg"` 로 지정하세요. 비워두면 샘플 그림이 그려집니다.
- `KIT`: 인스타그램 소개글·캡션·해시태그 문구

## 무료로 공개하기 (GitHub Pages)
저장소 Settings → Pages → Branch 선택 후 `/gallery` 경로의 `index.html`이 열립니다.
(Pages는 루트나 `/docs`만 고를 수 있으니, 필요하면 이 폴더를 `docs/`로 옮기세요.)
