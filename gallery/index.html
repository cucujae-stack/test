Artist

작가 소개

쉰여섯에 동네 문화센터에서 처음 유화를 배웠습니다. 베란다 화분, 고향 바다, 시장에서 사 온 작약처럼 매일 곁에 있는 것들을 그립니다.

한 작품에 보통 2~3주가 걸립니다. 물감이 충분히 마른 뒤 바니시로 마감해서 보내드립니다.

구매 안내

  1. 작품 고르기

    마음에 드는 그림을 눌러 크기와 가격을 확인하세요.

  2. 카카오톡으로 문의

    버튼을 누르면 문의 문장이 복사되고 카카오톡이 열려요. 붙여넣기만 하세요.

  3. 입금

    작가 본인 명의 계좌(예금주 ○○○)로 입금하시면 작품을 예약해 둡니다.

  4. 배송·직접 수령

    입금 확인 후 3~5일 안에 택배(무료)로 보내드려요. 화실에서 직접 받으셔도 됩니다.
